## ClipFlow 2.11.0

Every completed download now uses a consistent, production-friendly filename:

`Channel — Video title [identifier].mp4`

ClipFlow uses the YouTube channel whenever available. On other websites, it falls back in order to the creator, website domain or extractor name, so the source is never omitted. The short identifier prevents two videos with the same title from overwriting each other. Direct HLS/DASH streams and audio-only files follow the same convention.

### En français

Chaque téléchargement terminé utilise désormais une nomenclature cohérente et adaptée à la production :

`Chaîne — Titre de la vidéo [identifiant].mp4`

ClipFlow utilise la chaîne YouTube lorsqu’elle est disponible. Sur les autres sites, il emploie successivement le créateur, le domaine du site ou le nom de l’extracteur : la source ne manque donc jamais. L’identifiant court empêche deux vidéos portant le même titre de s’écraser. Les flux HLS/DASH directs et les fichiers audio suivent la même convention.
