# ClipFlow 2.13.3

Cette version corrige un problème de concurrence du moteur d’arrière-plan qui pouvait faire échouer plusieurs téléchargements simultanés près de 99 % ou laisser les suivants bloqués à 1 %.

## Corrections

- Un seul moteur ClipFlow traite désormais la file de téléchargements à la fois.
- Les demandes Chrome sont conservées sur disque jusqu’à leur prise en charge réelle.
- Après un arrêt inattendu, les anciens états orphelins sont signalés proprement au lieu de rester bloqués indéfiniment.
- Les demandes encore réellement présentes dans la file ne sont jamais supprimées par cette récupération.

Cette mise à jour contient l’application macOS, l’extension Chrome et le module Premiere Pro dans un installateur unique.
