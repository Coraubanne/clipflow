# ClipFlow 2.14.0

ClipFlow garde désormais automatiquement une installation propre en supprimant uniquement ses anciennes versions vérifiées.

## Nouveautés

- Nettoyage automatique après une installation, une mise à jour et le démarrage du moteur en arrière-plan.
- Une seule application ClipFlow est conservée dans les dossiers Applications de macOS.
- Seule la version la plus récente de Creator Bridge reste installée pour Premiere Pro.
- Les anciens dossiers d’extension gérés par ClipFlow sont retirés lorsqu’ils ne sont plus utilisés par Chrome.
- Une copie plus récente que l’application active n’est jamais supprimée.
- Les applications étrangères, les projets, les vidéos téléchargées et les autres fichiers personnels ne sont jamais concernés.
- Les anciennes archives de construction locales sont supprimées seulement après validation complète de leur remplaçante.

## Composants

- Application macOS ClipFlow 2.14.0, build 62, Apple Silicon.
- Extension Chrome ClipFlow 2.14.0.
- Creator Bridge 1.1.0 pour Premiere Pro.

Le DMG ci-dessous installe les trois composants. Le ZIP complet est destiné au mécanisme de mise à jour intégré et aux installations techniques.

---

ClipFlow now keeps its installation clean automatically by removing only older, verified ClipFlow components.

The cleanup runs after installation, automatic updates and background startup. It preserves newer copies, unrelated applications, downloaded media and personal files. This release includes ClipFlow 2.14.0 for Apple Silicon, the Chrome extension 2.14.0 and Creator Bridge 1.1.0 for Premiere Pro.
