## ClipFlow 2.12.1

This maintenance release makes the update indicator reliable after an upgrade. A status cached by the previous extension version is now discarded automatically, so the settings panel immediately checks and displays the version that is actually installed.

The streamlined destination menu introduced in 2.12.0 remains unchanged: Downloads, Premiere Pro and a custom folder are the only choices. Legacy Movies and Desktop settings migrate safely to Downloads.

### En français

Cette version de maintenance fiabilise l’indicateur de mise à jour après une installation. Un état mémorisé par l’ancienne version de l’extension est désormais automatiquement ignoré : le panneau de réglages vérifie et affiche immédiatement la version réellement installée.

Le menu de destination simplifié introduit dans la version 2.12.0 est conservé : seuls Téléchargements, Premiere Pro et un dossier personnalisé sont proposés. Les anciens réglages Films et Bureau sont automatiquement redirigés vers Téléchargements.
