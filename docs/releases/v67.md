## Public launch · Lancement public

ClipFlow is now presented as a professional media-acquisition workflow for video editors, audiovisual documentalists, archive researchers, journalists and documentary teams.

### What changed

- Public English and French project documentation.
- Anonymous update checks and installations from public GitHub Releases.
- Responsible-use and legal notices with an explicit no-DRM-circumvention scope.
- Privacy policy, security reporting process, contribution guide and third-party notices.
- Automated tests, Dependabot configuration and structured issue forms.
- SHA-256 verified distribution containing the macOS app, Chrome extension and Premiere Pro panel.

### En français

ClipFlow dispose désormais d’une présentation publique bilingue centrée sur les métiers du montage, de la documentation audiovisuelle et de la recherche d’archives. Les mises à jour publiques ne nécessitent plus de compte GitHub. La documentation précise les usages autorisés, la confidentialité, la sécurité, les licences tierces et l’absence de contournement DRM.

> ClipFlow is distributed outside the Mac App Store and Chrome Web Store. Follow the installation instructions in the README and use the software only for media you are authorized to download.
