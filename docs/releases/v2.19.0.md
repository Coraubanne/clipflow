### Français

Avec Premiere Pro comme destination, la carte 4K propose une option sans perte. ClipFlow copie les pistes compatibles ou encode la vidéo 4K 8 bits en H.264 sans perte. La piste AAC est copiée à l’identique. Creator Bridge importe le MP4 dans le projet actif. Le fichier peut être beaucoup plus volumineux.

### English

When Premiere Pro is the destination, the 4K card offers a lossless option. ClipFlow copies compatible tracks or encodes 8-bit 4K video as lossless H.264. The AAC audio is copied intact. Creator Bridge imports the MP4 into the active project. The file can be much larger.
