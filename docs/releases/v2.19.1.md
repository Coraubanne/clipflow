### Français

La carte 4K utilise automatiquement la conversion sans perte. ClipFlow copie directement les pistes compatibles et réencode l’image sans perte uniquement quand c’est nécessaire. Le MP4 local est finalisé en une seule passe. Une source incompatible affiche une erreur.

### English

The 4K card automatically uses lossless conversion. ClipFlow copies compatible tracks and uses lossless video encoding when needed. The local MP4 is finalized in a single pass. Unsupported sources show an error.
