## ClipFlow 2.13.0

Settings now open as a dedicated, distraction-free view. Video results, download progress and the audio-only option temporarily disappear; clicking the gear again restores the exact media view.

Amazon video cards now reliably display the poster supplied by the page’s player. ClipFlow copies that public image into the popup’s memory before rendering it, without writing a file or requesting broader Chrome permissions.

### En français

Les réglages s’ouvrent désormais dans une vue dédiée, sans éléments parasites. Les vidéos, la progression et l’option audio uniquement sont temporairement masquées ; un nouveau clic sur la roue restaure la vue des médias telle quelle.

Les cartes vidéo Amazon affichent maintenant de façon fiable l’image fournie par le lecteur de la page. ClipFlow copie cette image publique en mémoire avant de l’afficher, sans créer de fichier et sans demander d’autorisation Chrome supplémentaire.
