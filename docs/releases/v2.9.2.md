## ClipFlow 2.9.2

The extension settings are cleaner: the explanatory sentence below the interface-language selector has been removed. Detected-video cards now display the page or player thumbnail when one is available.

### En français

Les réglages de l’extension sont plus sobres : la phrase explicative sous le choix de langue de l’interface a été supprimée. Chaque proposition de vidéo affiche désormais la miniature fournie par la page ou le lecteur lorsqu’elle est disponible.

This is the first ClipFlow release published directly with a semantic version tag.
