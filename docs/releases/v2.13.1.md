## ClipFlow 2.13.1

### [Download ClipFlow for macOS](https://github.com/Coraubanne/clipflow/releases/download/v2.13.1/ClipFlow-Installer.dmg)

Open `ClipFlow-Installer.dmg`, then launch **Installer ClipFlow**. The ZIP and SHA-256 files listed below are technical assets used by the automatic updater; new users do not need them.

ClipFlow now removes browser notification counters such as `(168)` or `[168]` from media titles. The cleaned title is used both in the extension and in the final filename.

This patch includes the dedicated settings view and reliable Amazon thumbnails introduced in ClipFlow 2.13.0.

New installations now use the single `ClipFlow-Installer.dmg` file. The versioned ZIP and checksum remain release assets only for ClipFlow’s secure automatic updater.
