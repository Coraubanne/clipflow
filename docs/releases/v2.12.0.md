## ClipFlow 2.12.0

The Chrome extension has been redesigned for clarity without adding complexity. Its hierarchy, spacing and control sizes are more deliberate; video thumbnails are larger; download actions are easier to identify; and progress now combines the precise percentage with a visual track.

The interface uses a restrained monochrome glass treatment, subtle blue gradients, soft shadows, native dark mode and reduced-motion support. The destination menu now keeps only Downloads, Premiere Pro and a custom folder. Existing Movies or Desktop settings automatically return to Downloads.

This release also updates yt-dlp and the media/build dependencies, including the security-fixed Brotli 1.2.1 and Pillow 13.0.0 releases.

### En français

L’extension Chrome a été réorganisée pour être plus claire sans ajouter de complexité. La hiérarchie, les espacements et la taille des contrôles sont plus cohérents ; les miniatures sont plus grandes ; les actions de téléchargement sont plus faciles à identifier ; et la progression combine désormais le pourcentage précis avec une barre visuelle.

L’interface adopte un traitement monochrome translucide, de légers dégradés bleus, des ombres douces, un mode sombre natif et une gestion des animations réduites. Le menu de destination conserve uniquement Téléchargements, Premiere Pro et un dossier personnalisé. Les anciens choix Films ou Bureau reviennent automatiquement vers Téléchargements.

Cette version met également à jour yt-dlp et les dépendances média/de construction, dont les versions corrigées Brotli 1.2.1 et Pillow 13.0.0.
