ClipFlow 2.16.1 apporte la prise en charge de Firefox 140+ sur les Mac Apple Silicon. Chrome et Firefox utilisent le même compagnon macOS.

| Pour | Fichier à utiliser |
| --- | --- |
| Installer ClipFlow sur macOS | `ClipFlow-Installer.dmg` |
| Charger l’extension temporaire sous Firefox | `ClipFlow-Firefox-unsigned.xpi` |
| Mettre à jour depuis ClipFlow | Le bouton **Réglages → Chercher une mise à jour** utilise le ZIP complet et son empreinte SHA-256. |

Pour Firefox, lancez d’abord l’installateur macOS, puis chargez le XPI dans `about:debugging#/runtime/this-firefox`. Firefox retire le module temporaire au redémarrage.

Si **Premiere Pro** est la destination, le bouton de mise à jour vérifie aussi la version autonome de Creator Bridge.

[Guide d’installation en français](https://github.com/Coraubanne/clipflow/blob/main/README.fr.md#installer-clipflow)

## English

ClipFlow now supports Firefox 140+ on Apple Silicon Macs. Run `ClipFlow-Installer.dmg`, then load the unsigned XPI as a temporary add-on in Firefox. Use **Settings → Check for updates** for an existing installation. Creator Bridge has a separate update check when Premiere Pro is the selected destination.

[English installation guide](https://github.com/Coraubanne/clipflow#install)
