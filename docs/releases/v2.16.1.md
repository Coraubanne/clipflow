# ClipFlow 2.16.1

ClipFlow prend en charge Firefox 140 ou plus récent sur Mac Apple Silicon. Le même compagnon macOS assure la détection des téléchargements en cours, le traitement des médias et l’envoi dans Premiere Pro pour Chrome et Firefox.

- **Nouvelle installation**. Téléchargez `ClipFlow-Installer.dmg`.
- **Firefox**. Chargez `ClipFlow-Firefox-unsigned.xpi` comme module temporaire dans `about:debugging#/runtime/this-firefox`. Firefox retire le module au redémarrage. Une installation permanente exige la signature Mozilla.
- **Creator Bridge**. Lorsque Premiere Pro est la destination choisie, le bouton de mise à jour vérifie aussi le module partagé. Une seule copie du plugin sert aux deux navigateurs.

Le ZIP complet et son empreinte SHA-256 sont destinés au programme de mise à jour intégré.

## English

Firefox 140 or newer is supported on Apple Silicon Macs. Run the DMG to install the shared macOS companion, then load the unsigned XPI as a temporary add-on in Firefox. Creator Bridge has a separate update check when Premiere Pro is selected as the destination.
