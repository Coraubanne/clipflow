ClipFlow 2.16.2 corrige une erreur d’encodage qui pouvait bloquer l’installation d’une mise à jour automatique sur macOS.

Si votre version actuelle affiche une erreur `unknown encoding: utf-16be`, utilisez `ClipFlow-Installer.dmg` pour effectuer cette mise à niveau. Les options et l’installation des navigateurs sont décrites dans le [guide ClipFlow](https://github.com/Coraubanne/clipflow/blob/main/README.fr.md).

## English

This release fixes an encoding error that could stop automatic updates on macOS. If your existing version reports `unknown encoding: utf-16be`, use `ClipFlow-Installer.dmg` for this upgrade.
