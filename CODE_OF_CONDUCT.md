# Code of conduct

ClipFlow contributors and maintainers are expected to keep every project space professional, welcoming and focused on constructive technical collaboration.

Harassment, discrimination, threats, publication of private information, copyright abuse and requests for unlawful access-control circumvention are not accepted. Technical disagreement is welcome when expressed respectfully and supported with evidence.

Maintainers may edit or remove contributions that violate these expectations and may restrict participation when necessary to protect the community or project. Sensitive conduct reports should be sent privately through a GitHub Security Advisory rather than posted publicly.

This policy applies to repository issues, pull requests, discussions and other spaces representing ClipFlow.
